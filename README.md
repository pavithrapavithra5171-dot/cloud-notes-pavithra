Cloud Notes - Android App
Developed by: Pavithra | College Project 2026 Department: Mobile App Development Lab

📝 About The Project
Cloud Notes is a simple and lightweight Android note-taking application. This app helps users to create, edit, delete, and manage their daily notes easily. The app works completely OFFLINE and saves all data in phone's local storage, so no internet is needed. It is built using web technologies and converted to Android app using CapacitorJS.

This project is submitted as part of Mobile App Development Lab final year project.

✨ Features
Add Notes - Create new notes with Title and Detailed Content
Edit Notes - Update or modify any existing note
Delete Notes - Remove unwanted notes with confirmation
Search Notes - Instant and fast search by title or content
Export Notes - Backup all your notes as JSON or TXT file
Import Notes - Restore your notes from backup file easily
Offline Storage - Uses Browser LocalStorage, 100% offline, no data loss
Dark/Light Theme - Beautiful and modern UI with theme toggle
Responsive Design - Works on all Android screen sizes
Lightweight APK - Very small size and fast performance
🛠️ Tech Stack Used
Frontend: HTML5, CSS3, JavaScript (Vanilla JS)
Framework: CapacitorJS by Ionic - To convert Web App to Android App
Storage: Browser LocalStorage API
IDE / Build Tool: Visual Studio Code, Android Studio
Language: JavaScript
Platform: Android

📱 How to Install and Run on Android Phone
Copy cloud-notes-pavithra.apk file to your Android phone
Open File Manager and tap on the APK
Allow "Install from Unknown Sources" if asked
Install and open "Cloud Notes" app
Start taking your notes!
💻 How to Run for Development (For Teachers)
Open Project in VS Code cd cloud-notes
Install Dependencies npm install
Run on Web Browser (For Testing) Open www/index.html in browser
Build for Android npx cap copy android npx cap open android Then click on RUN button ▶️ in Android Studio
📦 How I Built the APK
In Android Studio: Go to Build > Build App Bundles or APKs > Build APK(s) Wait for build to complete. APK Location on Laptop: android/app/build/outputs/apk/debug/app-debug.apk I renamed it to cloud-notes-pavithra.apk for easy submission.
